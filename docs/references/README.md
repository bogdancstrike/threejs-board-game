# Visual-reference index

The `user-provided/` folder holds resized copies of the user’s reference screenshots and the earlier in-chat concept renders. These are art-direction guides, **not** screenshots from the current GitHub game.

The `concepts/` folder contains newly authored schematic drawings (93-tile path, elevation profile, ten-world board, moodboard). They are **not** accurate rendered captures of the repository; they are proposed design diagrams.

The actual repository includes `public/previews/{verdant,dragonkind,frost,desert,sakura,ember,tide,mycelium,astral,clockwork}.webp`, but the remote binary files could not be incorporated here. The link manifest `repository/EXISTING_RENDER_LINKS.md` gives direct URLs to them. The existing project’s GLBs are not bundled; reference their canonical repository paths and respect attribution.
